# 移动端审批操作面板布局设计

## 问题

需求详情在小于 620px 的窗口中将 `.detail-grid` 改为 `display: block`。块布局不支持子元素的 `order` 排序，因此 DOM 中位于成果内容之后的操作面板被放到长页面底部，编码自测审批需要滚动很久才能操作。

## 设计

- 小于 620px 时，详情容器使用纵向 Flex，而不是块布局。
- 操作面板继续使用 `order: -1`，稳定显示在当前阶段成果之前。
- 操作面板保持普通文档流，不使用固定底栏，避免遮挡移动端底部导航和内容。
- 621px 以上保留现有网格布局。
- 901px 以上的双栏布局中，操作面板使用 `position: sticky`，滚动长成果时保持可见；吸顶距离避开页面上边缘。
- 历史阶段和当前阶段使用同一布局，不复制审核按钮。

## 验收

- 390px 手机宽度打开编码自测详情，操作面板位于成果内容上方。
- 介于 621px 和 900px 的窄桌面宽度，操作面板仍位于成果内容上方。
- 大于 900px 时保持右侧栏，并在滚动时吸顶。
- 页面无横向溢出，操作面板不覆盖底部导航。
